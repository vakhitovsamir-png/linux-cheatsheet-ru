## Файлы

| Команда | Что делает |
|---|---|
| `ls -la` | Список файлов, включая скрытые, с размерами и правами |
| `cd ~` | Перейти в домашнюю папку |
| `cd ..` | Подняться на уровень выше |
| `pwd` | Показать, в какой папке вы находитесь |
| `mkdir -p папка/вложенная` | Создать папку (и вложенные) |
| `cp -r источник цель` | Копировать файл или папку |
| `mv старое новое` | Переместить или переименовать |
| `rm файл` | Удалить файл (в корзину не попадает!) |
| `rm -r папка` | Удалить папку со всем содержимым (осторожно) |
| `touch файл` | Создать пустой файл |
| `cat файл` | Показать содержимое файла |
| `less файл` | Читать длинный файл постранично (q — выход) |
| `head -n 20 файл` | Первые 20 строк файла |
| `tail -f файл.log` | Следить за концом файла в реальном времени |
| `ln -s цель ссылка` | Создать символическую ссылку |

## Поиск

| Команда | Что делает |
|---|---|
| `find . -name "*.pdf"` | Найти файлы по имени в текущей папке |
| `grep -rn "слово" .` | Найти текст внутри файлов |
| `which программа` | Где лежит программа |
| `locate имя` | Быстрый поиск по базе файлов (нужен пакет plocate) |
| `history \| grep слово` | Найти команду в истории терминала |

## Права

| Команда | Что делает |
|---|---|
| `chmod +x скрипт.sh` | Сделать файл исполняемым |
| `chmod 644 файл` | Права: владелец читает и пишет, остальные читают |
| `chown $USER:$USER файл` | Сделать себя владельцем файла (нужен sudo) |
| `sudo команда` | Выполнить команду от администратора |
| `whoami` | Под каким пользователем вы работаете |

## Пакеты (apt)

| Команда | Что делает |
|---|---|
| `sudo apt update` | Обновить список пакетов |
| `sudo apt upgrade` | Установить доступные обновления |
| `sudo apt install имя` | Установить программу |
| `sudo apt remove имя` | Удалить программу |
| `sudo apt autoremove` | Удалить ненужные зависимости |
| `apt search слово` | Найти пакет по слову |
| `sudo apt clean` | Очистить кэш скачанных пакетов |
| `flatpak install flathub имя` | Установить программу из Flathub |
| `flatpak update` | Обновить Flatpak-программы |

## Система

| Команда | Что делает |
|---|---|
| `uname -a` | Версия ядра и система |
| `lsb_release -a` | Версия дистрибутива |
| `df -h` | Сколько места занято на дисках |
| `du -sh папка` | Размер папки |
| `free -h` | Оперативная память: занято и свободно |
| `top` | Процессы и нагрузка (q — выход) |
| `htop` | Удобный монитор процессов (нужно установить) |
| `uptime` | Сколько система работает без перезагрузки |
| `lscpu` | Сведения о процессоре |
| `lsblk` | Диски и разделы |
| `lspci \| grep -i vga` | Какая у вас видеокарта |
| `journalctl -p 3 -xb` | Ошибки с последней загрузки системы |
| `sudo reboot` | Перезагрузить компьютер |
| `sudo shutdown now` | Выключить компьютер |

## Процессы

| Команда | Что делает |
|---|---|
| `ps aux \| grep имя` | Найти процесс по имени |
| `kill PID` | Завершить процесс по номеру |
| `killall имя` | Завершить все процессы с этим именем |
| `xkill` | Кликнуть по зависшему окну, чтобы закрыть его |
| `systemctl status служба` | Состояние службы |
| `sudo systemctl restart служба` | Перезапустить службу |
| `sudo systemctl enable служба` | Включить автозапуск службы |

## Сеть

| Команда | Что делает |
|---|---|
| `ip a` | Ваши сетевые адреса |
| `ping -c 4 ya.ru` | Проверить, есть ли связь |
| `curl ifconfig.me` | Узнать внешний IP-адрес |
| `ss -tulpn` | Какие порты открыты |
| `nmcli device wifi list` | Список доступных Wi-Fi сетей |
| `wget ссылка` | Скачать файл по ссылке |
| `ssh пользователь@адрес` | Подключиться к другому компьютеру по SSH |
| `scp файл пользователь@адрес:/путь` | Скопировать файл на другой компьютер |

## Архивы

| Команда | Что делает |
|---|---|
| `tar -czf архив.tar.gz папка` | Упаковать папку в tar.gz |
| `tar -xzf архив.tar.gz` | Распаковать tar.gz |
| `zip -r архив.zip папка` | Упаковать в zip |
| `unzip архив.zip` | Распаковать zip |

## Терминал

| Команда | Что делает |
|---|---|
| `Ctrl + C` | Остановить текущую команду |
| `Ctrl + R` | Поиск по истории команд |
| `Tab` | Автодополнение имён и команд |
| `Ctrl + L` | Очистить экран (или команда clear) |
| `!!` | Повторить прошлую команду (sudo !! — с sudo) |
| `man команда` | Подробная справка по команде |
| `команда --help` | Краткая справка по команде |
